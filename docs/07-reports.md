# Falak POS — كتالوج التقارير

> الملف 7 · المواصفة الكاملة لشاشة التقارير: المبادئ، ثم كل تقرير بأعمدته وفلاتره ومصدره، بمستوى أنظمة المحاسبة الاحترافية. يحل محل السطر المختصر "تقارير أساسية" في الملفات السابقة.
> ما يُبنى في الإصدار 1.0 معلَّم بـ ✦؛ الباقي في 1.x بنفس البنية دون تغيير في قاعدة البيانات.

---

## 1. مبادئ تسري على كل تقرير

1. **إطار موحّد:** كل تقرير يفتح داخل نفس القالب: شريط فلاتر أعلى، بطاقات ملخص (KPIs)، الجدول، ثم الإجماليات. لا تقارير بتصميم خاص.
2. **الفلاتر القياسية:** فترة (اليوم/أمس/هذا الأسبوع/هذا الشهر/الشهر الماضي/مخصص) + فرع + مخزن + مستخدم/كاشير + عملة العرض. تقارير الأصناف تضيف تصنيفاً ومورداً؛ تقارير الذمم تضيف عميلاً/مورداً. الفلاتر تُحفظ لكل مستخدم.
3. **مقارنة بالفترة السابقة:** كل KPI يعرض نسبة التغير عن الفترة المكافئة السابقة (اليوم مقابل أمس، الشهر مقابل الشهر الماضي).
4. **Drill-down:** كل رقم قابل للنقر ينزل لمستواه الأدنى: إجمالي اليوم ← فواتير اليوم ← الفاتورة نفسها. لا أرقام "ميتة".
5. **التصدير والطباعة:** كل تقرير يصدَّر Excel (بنفس الأعمدة والإجماليات، أرقاماً لا نصوصاً) وPDF بترويسة المحل (شعار، اسم، فترة، تاريخ الطباعة، اسم المستخدم)، وطباعة A4 مباشرة. التقارير القصيرة (Z، ملخص اليوم) تُطبع حرارياً أيضاً.
6. **العملة:** التقارير تُحسب بالعملة الأساسية (`amount_base`)، مع خيار عرض تفصيل العملات في تقارير الصندوق. سعر الصرف المستخدم هو المثبّت في كل حركة، لا سعر اليوم.
7. **الصلاحيات:** التكلفة والربح لا تظهران إلا لحامل `products.view_cost` / `reports.profit` — نفس التقرير يُعرض بلا هذين العمودين لمن لا يملكها.
8. **الفواتير الملغاة** تُستثنى من الإيراد وتظهر في تقرير الإلغاءات فقط. المرتجعات تُخصم وتظهر كسطر مستقل في الإجماليات.
9. **الأداء:** أي تقرير ≤ ثانيتين على سنة بيانات (مليون سطر بيع). ما يتجاوزها يُبنى له ملخص يومي مسبق (`report_daily_*` materialized views تُحدَّث ليلياً — تُضاف عند الحاجة لا الآن).
10. **جدولة التقارير:** أي تقرير يمكن جدولته للإرسال بريداً أو واتساب (يومي/أسبوعي/شهري) عبر نظام الرسائل (الملف 08) — ملخص اليوم للمالك هو الحالة الأولى.

## 2. الكتالوج

### 2.1 المبيعات

| التقرير | الأعمدة الرئيسية | ملاحظات |
|---|---|---|
| ✦ ملخص اليوم (لوحة اليوم) | مبيعات، فواتير، متوسط الفاتورة، مرتجعات، ربح إجمالي، نقد/بطاقة/آجل، مبيعات بالساعة (رسم) | شاشة البداية للمالك، وأساس الرسالة اليومية |
| ✦ المبيعات التفصيلية | رقم الفاتورة، التاريخ/الوقت، الفرع، الكاشير، العميل، الإجمالي، الخصم، الضريبة، الصافي، طريقة الدفع، الحالة | من `sales`؛ drill للفاتورة |
| ✦ المبيعات اليومية/الشهرية المجمّعة | اليوم/الشهر، عدد الفواتير، الإيراد، الخصومات، الضريبة، التكلفة، الربح، هامش % | §5.8 في الملف 02 |
| ✦ المبيعات حسب الصنف | الصنف، الكمية (بالوحدة الأساسية)، الإيراد، التكلفة، الربح، هامش %، % من الإجمالي | الأكثر/الأقل مبيعاً بنفس التقرير (فرز) |
| ✦ المبيعات حسب التصنيف | تصنيف (بمستوياته)، كمية، إيراد، ربح، % | شجري قابل للطي |
| ✦ المبيعات حسب الكاشير | الكاشير، فواتير، إيراد، خصومات ممنوحة، مرتجعات، إلغاءات، متوسط الفاتورة | مقارنة الموظفين |
| ✦ المبيعات حسب طريقة الدفع | الطريقة، العملة، المبلغ، عدد العمليات | يطابق حركات الصندوق |
| المبيعات حسب العميل | العميل، فواتير، إيراد، ربح، آخر شراء | لعملاء الجملة |
| المبيعات حسب الساعة/اليوم في الأسبوع | مصفوفة حرارية ساعات × أيام | لجدولة الموظفين |
| ✦ المرتجعات | الفاتورة الأصلية، المرتجع، الصنف، الكمية، المبلغ، السبب، من وافق | من `doc_type='return'` |
| ✦ الإلغاءات والحذف | الفاتورة، من ألغى، السبب، المبلغ، الوردية | من `sales.voided` + `audit_logs` — تقرير "الخوف" الذي يشتري لأجله المالك |
| ✦ الخصومات الممنوحة | الفاتورة، السطر، الخصم، النسبة، الكاشير، من وافق | كشف تجاوزات |
| العروض | العرض، مرات التطبيق، قيمة الخصم، الإيراد المتولد | فعالية العروض |

### 2.2 المشتريات والموردون

| التقرير | الأعمدة | ملاحظات |
|---|---|---|
| ✦ المشتريات التفصيلية | رقمنا، رقم فاتورة المورد، المورد، التاريخ، الإجمالي، المدفوع، المتبقي، الحالة | |
| ✦ المشتريات حسب الصنف | الصنف، الكمية، متوسط التكلفة، آخر تكلفة، الموردون | تفاوض الشراء |
| ✦ المشتريات حسب المورد | المورد، فواتير، إجمالي، مدفوع، رصيد | |
| ✦ كشف حساب مورد | حركة بحركة برصيد جارٍ (فاتورة/دفعة/مرتجع) | من `supplier_transactions`؛ يُطبع ويُرسل |
| ✦ أعمار ذمم الموردين (Aging) | المورد، الرصيد، جارٍ، 1–30، 31–60، 61–90، +90 يوماً | حسب `due_date` |
| مرتجعات الشراء | الفاتورة، الصنف، الكمية، السبب | |
| البونص المستلم | المورد، الصنف، كمية البونص، قيمتها بالتكلفة | خاص بسوقنا |

### 2.3 المخزون

| التقرير | الأعمدة | ملاحظات |
|---|---|---|
| ✦ أرصدة المخزون | الصنف، المخزن، الرصيد، متوسط التكلفة، قيمة المخزون، الحد الأدنى، الحالة (شارة) | الإجمالي = قيمة المخزون الحالية |
| ✦ حركة صنف (كارت الصنف) | التاريخ، نوع الحركة، المرجع، داخل، خارج، الرصيد الجاري، التكلفة | من `stock_movements` برصيد تراكمي |
| ✦ نقص المخزون وإعادة الطلب | الصنف، الرصيد، الحد الأدنى، كمية الطلب المقترحة، المورد الأخير | يتحول لطلب شراء بزر واحد |
| ✦ قرب الانتهاء والمنتهي | الصنف، الدفعة، التشغيلة، تاريخ الانتهاء، الأيام المتبقية، الكمية، القيمة | شرائح 30/90/180 يوماً؛ وحدة expiry |
| ✦ تقييم المخزون بتاريخ | الصنف، الرصيد في التاريخ، التكلفة، القيمة | إعادة بناء من الحركات؛ للجرد المالي السنوي |
| ✦ فروقات الجرد | الجرد، الصنف، المتوقع، المعدود، الفرق، القيمة، السبب، من اعتمد | من `stocktake_lines` |
| ✦ التسويات والهالك | التاريخ، الصنف، الكمية، القيمة، السبب، المستخدم | movement_type='adjustment' |
| التحويلات بين المخازن | التحويل، من/إلى، الأصناف، الحالة | |
| الراكد (بلا حركة) | الصنف، آخر بيع، الرصيد، القيمة المجمّدة | فترة قابلة للضبط (90 يوماً) |
| تقرير التقطيع | التشغيلة، المدخل، القطع الناتجة، الهالك %، تكلفة الكيلو الفعلية لكل قطعة | وحدة breakdown |

### 2.4 العملاء والذمم

| التقرير | الأعمدة | ملاحظات |
|---|---|---|
| ✦ أرصدة العملاء | العميل، الهاتف، الرصيد، الحد الائتماني، آخر دفعة، آخر شراء | فرز بالأعلى ديناً |
| ✦ كشف حساب عميل | حركة بحركة برصيد جارٍ | §5.7؛ يُطبع ويُرسل واتساب |

### 2.5 الصندوق والورديات والمصروفات

| التقرير | الأعمدة | ملاحظات |
|---|---|---|
| ✦ تقرير الوردية (Z) | الفتح/الإغلاق، الفواتير، المبيعات، المرتجعات، حسب طريقة الدفع، **لكل عملة**: افتتاحي/متوقع/معدود/الفرق، المصروفات، الإيداعات | يُطبع حرارياً عند الإغلاق ويُرسل للمالك |
| ✦ الورديات المجمّعة | الوردية، الكاشير، الصندوق، المدة، المبيعات، الفرق (شارة) | كشف العجوزات المتكررة |
| ✦ حركة الصندوق التفصيلية | التاريخ، النوع، المرجع، العملة، داخل، خارج، الرصيد | من `cash_movements` |
| ✦ المصروفات | التاريخ، التصنيف، الوصف، المبلغ، من أين صُرف، المستخدم، المرفق | مجمّعة بالتصنيف مع رسم |
| التدفق النقدي اليومي | اليوم، مقبوضات (بيع + تحصيل)، مدفوعات (موردون + مصروفات)، الصافي | لكل عملة |

### 2.6 المالية والضريبة (ما يجعله "مثل أنظمة المحاسبة")

| التقرير | الأعمدة | ملاحظات |
|---|---|---|
| ✦ قائمة الدخل المبسطة (P&L) | الإيراد − المرتجعات = صافي المبيعات؛ − تكلفة البضاعة = مجمل الربح؛ − المصروفات (بالتصنيف) = صافي الربح؛ الهوامش % | شهرية مع مقارنة 12 شهراً؛ **ليست** دفتر أستاذ، لكنها تكفي صاحب المحل وتُبنى من بياناتنا الموثوقة |
| ✦ تقرير الضريبة (VAT) | مبيعات خاضعة/معفاة، ضريبة المبيعات (مستحقة)، مشتريات خاضعة، ضريبة المشتريات (قابلة للخصم)، **الصافي المستحق** | بفترة الإقرار (شهري/ربعي)؛ جاهز للمحاسب القانوني |
| ✦ ملخص الذمم | إجمالي لنا (عملاء) − إجمالي علينا (موردون) = صافي المركز | مع رسم تطوره |
| قيمة المخزون + الربح غير المحقق | التكلفة مقابل سعر البيع للرصيد الحالي | |
| ملخص للمحاسب (تصدير) | ملخص يومي: مبيعات، ضريبة، تكلفة، نقد/بطاقة/آجل، مصروفات، تحصيلات — CSV/Excel | هذا هو جسر برنامج المحاسبة (الملف 08 §5) |

### 2.7 الصيدلية (وحدتها)

✦ الأدوية المراقبة المصروفة (الدواء، الكمية، الوصفة، الطبيب، المريض) · ✦ مطالبات التأمين حسب الشركة (فترة، حصة الشركة، حصة المريض، حالة المطالبة — يُصدَّر بصيغة كل شركة) · صرف مادة فعالة (كل الأصناف الحاملة لها).

### 2.8 النظام والرقابة

✦ سجل العمليات المصفّى (من، ماذا، متى، قبل/بعد) · ✦ عمليات تحتاج انتباهاً (خصومات فوق حد، بيع تحت الأدنى، فتح درج بلا بيع، تجاوز حد ائتماني — كلها بموافقة من) · تقرير المستخدمين (آخر دخول، عدد العمليات).

## 3. ما يظهر في لوحة المالك (الموبايل)

اليوم الآن: مبيعات، فواتير، الصندوق لكل عملة، آخر 10 فواتير · هذا الشهر: إيراد وربح مقابل الشهر الماضي · التنبيهات · أعلى 5 ديون · الورديات المفتوحة وفروق آخر الورديات. كل بطاقة تفتح نسخة قراءة من التقرير الكامل.

## 4. خطة البناء

تُستبدل مهمة 3.3 في الملف 04 بـ: بناء **إطار التقارير** (الفلاتر، KPIs، الجدول، التصدير، الطباعة، الصلاحيات) يومان، ثم كل تقرير ✦ نصف يوم إلى يوم لأنها SQL + أعمدة داخل الإطار. تقارير ✦ عددها 27 وتتوزع: 12 في M3، 8 مع وحدات M4 (صيدلية/ملحمة/ذمم متقدمة)، والبقية في M5–M6. غير المعلّمة تُبنى بعد الإطلاق حسب طلب العملاء.
