# ADR-002 — الأموال بـ decimal لا float

- **الحالة:** معتمد · 2026-09-05
- **المرجع:** `docs/02-database.md §1` (الأنواع الرقمية) و`§12` (ما يجب على المطوّر تذكّره)
- **المهمة:** 1.9 في `docs/04-execution-plan.md`

## السياق

نظام يبيع بعدة عملات (شيكل بمنزلتين، **دينار أردني بثلاث منازل**، دولار)، ويحسب ضريبة شاملة ومضافة، وخصومات على السطر والفاتورة، ويقارن الصندوق المعدود بالمتوقع قرشاً بقرش. أي خطأ تقريب يظهر مباشرة كعجز صندوق يتهم به كاشير بريء.

`0.1 + 0.2 !== 0.3` في IEEE-754، وضرب سعر × كمية موزونة بثلاث منازل يراكم الخطأ عبر آلاف الفواتير.

## القرار

1. **في القاعدة:** مبالغ `numeric(14,2)`، كميات `numeric(14,3)`، تكلفة الوحدة `numeric(14,4)`، سعر صرف `numeric(14,6)`، نسب `numeric(6,3)`. **ممنوع `float`/`double precision` لأي حقل مالي أو كمية.**
2. **في الكود:** كل عملية حسابية على المال تمر عبر `decimal.js` داخل `packages/core`. `number` في JavaScript مسموح **للعرض فقط** بعد التقريب النهائي.
3. **سائق القاعدة (`pg`) يعيد `numeric` كنص** لا كرقم — وهذا مقصود ولا يُعطَّل. التحويل إلى `Decimal` يتم عند الحدود.
4. **التقريب يحترم `currencies.decimals`** لا رقمين ثابتين: الشيكل 2، الدينار 3. دالة تقريب واحدة في `packages/core` تأخذ العملة، ولا يُقرَّب في أي مكان آخر.
5. **الجمع قبل التقريب:** تُجمع الأسطر بدقة كاملة ويُقرَّب الإجمالي مرة واحدة، فلا تتراكم أخطاء التقريب عبر السطور.
6. ESLint يمنع `parseFloat` عالمياً كتذكير.

## البدائل المرفوضة

| البديل | لماذا رُفض |
|---|---|
| `number` عادي بتقريب في النهاية | يفشل عند الكميات الموزونة (1.235 كغ × 78.50) وعبر التراكم في التقارير الشهرية |
| أعداد صحيحة بالأصغر وحدة (فلس/أغورة) | يعمل، لكن اختلاف عدد المنازل بين الشيكل والدينار يجعل "الوحدة الأصغر" مختلفة لكل عملة، ويحوّل كل ضرب ونسبة إلى منطق يدوي هشّ |
| `BigInt` | لا يدعم الكسور، ويحتاج نفس منطق المقياس اليدوي |

## الأثر

- `packages/core` يعتمد على `decimal.js` وحدها، بلا أي اعتماد على القاعدة أو الشبكة، فتُختبر كل الحالات بسرعة.
- كل قيمة مالية تعبر واجهة الـ API تُنقل **كنص** (`"1248.50"`) لا كرقم JSON، فلا يفسدها `JSON.parse`.
- أي حقل مالي جديد يُضاف مستقبلاً يجب أن يكون `numeric` — يُفحص في مراجعة الترحيلات.
