# Falak POS — وثائق المشروع

توضع هذه الملفات في مجلد `docs/` داخل مستودع المشروع، وهي المرجع قبل كتابة أي كود. آخر تحديث: 2026-09-05.

| الملف | المحتوى |
|---|---|
| `01-project-and-permissions.md` | الفكرة والنطاق، الوحدات وأنواع النشاط، الأدوار الستة، مصفوفة الصلاحيات الكاملة، العمليات الحساسة، قسم الإعدادات (§11: الوحدات، الضريبة، محرر الصلاحيات، أزرار الكاشير)، المسرد |
| `02-database.md` | قاعدة البيانات: المبادئ، القرارات، التريجرات، الاستعلامات الحرجة، مفاتيح الإعدادات، المزامنة، الترحيلات، مرجع الجداول الـ65 كاملة، والـ DDL في النهاية |
| `03-design-system.md` | الهوية: الألوان (بلا أخضر — ثلاثة ألوان دلالية)، الخطوط، المسافات، كل مكوّن بقيمه، مواصفة شاشة الكاشير والاختصارات، الطباعة، RTL، الوضع الداكن، tokens.css وTailwind config جاهزان |
| `04-execution-plan.md` | 12 أسبوعاً، 6 مراحل، توزيع على الفريق A/B/C، كل مهمة بتقديرها ومعيار إنجازها، المخاطر، قائمة الإطلاق |
| `05-marketing-and-pricing.md` | السوق والمنافسون، الباقات والإضافات (نسخ سحابي، رسائل)، البيع النهائي والوكلاء، القنوات، التكاليف، ثلاثة سيناريوهات مالية ونقاط التعادل، قيمة المشروع عند البيع |
| `06-cloud-architecture.md` | قرار Supabase + خدمة falak-cloud، الهويات الثلاث، RLS، الدلاء، المزامنة، تفعيل العميل، المفاتيح، النسخ السحابي كخدمة مدفوعة |
| `07-reports.md` | كتالوج التقارير: 10 مبادئ + ~40 تقريراً في 8 مجموعات (27 منها في الإصدار 1.0)، ومنها قائمة الدخل وتقرير الضريبة وأعمار الذمم |
| `08-messaging-and-accounting.md` | الرسائل بريد/واتساب (المعمارية، القوالب، التسعير) + قواعد التجهيز للربط مع برنامج محاسبة فلك المستقبلي |
| `falak_pos_schema.sql` | الـ DDL الكامل: 65 جدولاً + تريجرات + بيانات أولية، مُختبر على PostgreSQL 16 |
